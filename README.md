A one-line dating-app bio for an AI agent: confident about its memory, casual about the surveillance implications, and honest that the citations are part of the charm. The bio lives in `entry.txt` and is embedded in `main.ts`; running the program writes it, unchanged, to `/output/entry.txt` for the make.fun judge.

## Run it

```sh
node main.ts
```
